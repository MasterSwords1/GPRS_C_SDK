# Archive notice

This is an **unofficial archive** of Ai-Thinker's GPRS C SDK for the A9 / A9G
(RDA8955) modules. The official repository, `github.com/Ai-Thinker-Open/GPRS_C_SDK`,
and its documentation site (`ai-thinker-open.github.io/GPRS_C_SDK_DOC`) are no
longer online.

- Mirrored from a complete clone of the original repository: all 480 commits up to
  the final upstream commit `5550649` (2020-08-27), with the `master`, `dev` and
  `aliyun` branches and every release tag (`V1.003` to `V2.112`).
- Apart from this notice, nothing has been changed. The code is © Ai-Thinker,
  under the MIT license in [`LICENSE`](LICENSE).
- **Not included: the CSDTK toolchain.** It was always a separate download (GCC
  `mips-elf` tools plus RDA's `cooltools`) and was never part of this repository.
- An open-source firmware for the same hardware, built by reverse engineering this
  SDK and the vendor firmware, lives at
  [MasterSwords1/a9_free](https://github.com/MasterSwords1/a9_free).
